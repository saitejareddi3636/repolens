# RepoLens design
Working surface: a source atlas, not a marketing homepage. The architecture map is the visual centerpiece, supported by a repository rail and an evidence inspector.
Palette: porcelain #f5f7fa, paper #ffffff, ink #172a40, cobalt #315ee8, teal #168b82, muted #68788c. Color denotes module layers, never truthfulness alone.
Type: locally bundled Inter variable sans for navigation and reading; system monospace only for actual code and file paths.
Desktop: repository rail | map or walkthrough | source inspector. Mobile: vertically stacked with horizontally scrollable graph. Left-aligned text; generous working space.
Motion: selected paths respond to navigation; no decorative particles or automatic panning. Respect reduced motion.
Evidence: static imports are verified by AST parsing; generated interpretations are explicitly labeled and citations bounded against stored source. No fake live activity or invented metrics.
Review: avoided a generic dashboard of stat cards. The central artifact is the graph itself, with code evidence always one interaction away.
